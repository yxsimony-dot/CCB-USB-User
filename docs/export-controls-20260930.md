# 导出流水控件

在顶部“启动业务”右侧新增 1～12 的不可编辑下拉框，默认选择 1，右侧为“导出流水”按钮。选中值通过 LauncherViewModel.SelectedExportNumber 双向绑定，保存在当前窗口内存中，不写入配置；未定义月份等业务含义。

当前仅提供界面，导出按钮禁用并显示“导出流程待接入”提示，等待用户提供后续流程。原有环境安装、PIN、启动、自动登录及弹窗处理逻辑未修改。

验证：Release 全量 .NET 测试 877/877 通过，Windows x64 自包含发布成功。只读复核确认控件顺序、绑定和最小窗口宽度可容纳；未进行实际窗口渲染验证。暂存包与原发布目录对比仅 App DLL/PDB 变化。

部署状态见 artifacts/verification/export-controls-20260930/result.json。用户关闭程序后，已备份旧 App DLL/PDB 至系统临时目录并替换原发布文件，两项部署哈希与暂存清单一致。已核对唯一快捷方式指向原发布目录，工作区仅有一个主程序 EXE。重新打开后需点击“安装环境”刷新代理哈希绑定，无需重设 PIN。
