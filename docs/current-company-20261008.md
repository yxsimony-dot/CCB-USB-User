# 顶部当前公司显示

用户指定在顶部操作面板右侧显示公司名称，不显示证书编号，并明确采用登录网银后自动读取。当前公开证书主题及扩展不含客户公司全名，因此面板标题为“当前公司”，取当前网银账户页面信息，不把配置证书、本地证书缓存或 USB 型号当作公司归属。

新增只读 `CcbCurrentCompany.js`，按已验证的首页账户名称结构及流水结果页结构提取。限制 HTTPS 指定银行域名、同源 `/NCCB/` 文档、可见节点和有界 frame 深度；结果页核对可见名称与隐藏身份字段；不同公司出现时显示无法确认。密码/登录控件可见、公司字段空白、截断或格式异常时清空。无点击、登录、查询、下载、网络请求或本地公司映射。

`WpfCurrentCompanyDisplay` 在现有业务 USB 状态允许且导航完成后每两秒只读检查一次。连接和导航版本拦截旧异步结果；拔出、退出登录或重新导航清空，重插后必须重新成功导航，不能复用原页面公司。普通附件导航中止时，只允许原连接已完成页面识别准备的情况重新读当前文档，不恢复缓存名称。释放时停止计时器并取消等待。

右侧 330 宽信息卡显示公司全名并自动换行，最小 900×600 与默认 1280×820 均已检查。公司不写入配置或诊断日志。
