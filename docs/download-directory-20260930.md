# 下载目录设置

顶部“导出流水”旁新增“下载目录”，打开 Windows 文件夹选择器。选择后检查目录存在、可写，并保存到当前 Windows 用户的 `%LOCALAPPDATA%\UsbWebLauncher\download-settings.json`。取消不更改设置；未设置时使用桌面；设置重启后保留。界面显示当前目录，长路径可通过悬停查看。

流水导出开始时取得目录快照，原始 PDF 的临时文件与最终文件均写入该目录，继续验证 PDF 文件头、完成事件并无覆盖地发布。普通网页下载通过 WebView2 profile 的 DefaultDownloadFolderPath 使用同一目录，共享 profile 的子窗口也继承此设置；运行中更换立即作用于后续下载，已开始的下载不搬迁。浏览器原有下载提示和单次“另存为”能力保留。普通下载由 WebView2 处理同名文件，流水 PDF 沿用应用的加序号策略。

保存失败保留旧设置。配置损坏会显示重新选择目录提示。导出时目录不存在或不可写会停止并提示，主网页下载不可写时取消。WebView2 自身可以在下载前重新创建已删除的目录；若无法创建则仍需用户重新选择。设置位于本机用户目录，不写入银行认证配置，也不随 USB 移到其他电脑。

- 独立只读审查未发现需修复的问题。Release win-x64 自包含发布通过。
- 程序关闭时更新原入口的 App/Core/Windows DLL/PDB 共六项，逐项 SHA-256 与暂存一致，旧六项备份在系统临时目录。原快捷方式、银行配置、浏览器用户数据和 broker 保留。
