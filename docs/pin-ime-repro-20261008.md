## 隔离实验

自建普通原生 EDIT 的中文输入法开启时，合成按键进入组合态。独立子进程通过 `ImmGetDefaultIMEWnd` 和 `WM_IME_CONTROL` 读取开启状态、关闭目标 IME、再次读取确认关闭后，同样的虚拟键输入获得完全相同的合成字符。中文、日文布局开/关 4/4 成功。测试结束恢复测试环境原状态。

标准 ES_PASSWORD EDIT 会自己关闭 IME，合成输入同样正确；其行为不同于现场记录。实验没有读产品 PIN，也没有操作银行窗口。

## 修改

以下为首次 IME 修正的记录；提交前的第二次 IME 检查已由下文 10:52 回归修正撤除。

1. 密码框匹配及聚焦后，关闭该控件的 IME 并读取确认；不切换全局布局，不通过模拟快捷键切换输入法。
2. 构造按键前记录准备前后的环境；发送按键前及提交前再次只读确认 IME 关闭。
3. 无法查询、关闭失败、窗口失焦、超时或取消时停止，不再自动提交或重试。输入中途重新开启 IME 时也不点击确认。
4. 原有身份校验、单次 PIN 输入、最终焦点/超时检查与缓冲清理保留。
