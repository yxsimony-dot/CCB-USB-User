## 本轮已实现

- `--receipt-discovery` 启用本次启动的临时结构采集，正常启动默认关闭，不写入配置，不关闭设备监听。采集随 WebView 初始化建立并随其释放，最长 20 分钟、文件最大 2 MiB、后台队列最多 32 条。
- 扩充固定回单/分页标签、控件标识与快照内节点关系、checkbox/radio 勾选布尔，明确控件/字段截断。节点编号仅能关联同次快照，不能用作真实选择器。
- 记录页面结构、请求地址结构（不含参数值）、方法、响应类型、附件标记、新窗口来源和主页面下载事件。观察器不提交、不处理弹窗、不修改下载路径。若下载发生在浏览器默认子窗口，主页面可能只记录新窗口，需要保留该证据边界，不能据此声称捕获了子窗口响应。
- 不读取输入/选项值、Cookie、完整账号、交易或回单正文；原处理器只记函数名。只有 value 标签的 input 按钮可能没有固定文字标记，仍通过字段/处理器结构辅助识别，不能猜测对应关系。
- 命名策略新增不可变 ElectronicReceipt 类型及 CreateReceipt，流水默认类型和文件名保持原样。回单后缀、前导零、长度预算、净化、重名和并发不覆盖均有测试。
