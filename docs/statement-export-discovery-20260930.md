用户目标为导出本机当前年份、所选月份的第一条活期账户整月流水，保存银行原始 PDF 至桌面。用户已批准下一步先在原程序采集一次人工流程。本次仅增加临时观察功能，没有实现一键导出，导出按钮仍为原占位状态。

## 采集范围

WebView2 初始化后独立运行最多 20 分钟，每两秒采集一次允许的建行 /NCCB/ 页面及同源后代 frame 结构；采样不排队、不在登录业务链等待，相同快照去重。支持实际同源文档和继承 blank/srcdoc、动态 frame 的相对地址。最多 16 文档、4 层、每文档 6000 元素，frame 发现独立于元素遍历，快照总量上限 96 KiB。

记录固定业务标记、技术控件标识、表单字段名称/类型、动作地址及查询参数名称、事件处理函数名称。网络观察只使用已发送请求的地址结构、方法、响应状态、媒体分类和附件标记。下载事件只记录来源结构、媒体类型、编号和状态，不改默认下载路径、不接管下载窗口。POST 请求体、响应正文、参数值、输入值、Cookie、PIN、完整账号、流水正文和下载文件名不写入日志。POST 字段明确标记为 not-collected，不能据此声称已获取完整接口。

日志位于当前用户本机 `%LOCALAPPDATA%/UsbWebLauncher/logs/statement-discovery.jsonl`，每次运行重新创建，最多 2 MiB，后台队列最多 32 条，写入失败与业务隔离。达到时间或文件上限时停止采集；排队拒绝的页面快照可在下次采样重试。日志不属于交付哈希清单。

## 2026-09-30 实机发现

用户完成一次人工查询并下载，日志区间 16:13:53～16:14:33：10 次页面快照、53 次资源响应、2 次新窗口请求。没有主 WebView 的 download-start/download-state 记录。脱敏结构子集已保存到验证目录 live-evidence.json，无需依赖下次启动会覆盖的临时日志。

已核实的结构：

- 主界面活期账户入口关联 taskBar.createWin；列表位于嵌套 frame，表单 jhform，账户复选框 name=ACC_NO；交易明细按钮 name=Submit3，原处理函数 detailQuery。
- 日期查询为 jhform，起止字段 id/name=StDt、EdDt；确认控件 name=Submit4、type=submit，表单 onsubmit 为 go。查询为 POST，目标 /NCCB/NECV6B2BMainPlat_09_LH。
- 结果页存在 dlall/dlAll 和多份 PDF 菜单，原处理函数名均为 submitSelect，同时有 jhform 与 elecPrintForm。不能仅按 PDF 标签取任意第一个，需区分“下载全部”和其他菜单。
- 16:14:31.697 发生指向同一 LH 入口的新窗口请求。用户截图随后显示浏览器下载完成面板，用户确认直接下载；本机 Downloads 中找到 16:14:32.480 生成、50342 字节的对应 PDF，文件头为 %PDF-。只核对文件元数据及五字节文件头，没有读取流水正文。该文件目前位于下载目录，尚非自动保存桌面。

据此判断：网站很可能利用默认子窗口完成下载，主页面下载监听没有覆盖它。确切子窗口响应和请求体尚未采集；不能把推断写成已抓到 PDF 接口，也不能据主窗口零下载事件说用户下载失败。

推荐正式实现复用现有登录会话：通过已识别的页面入口及原有处理逻辑进入活期账户，选第一条账户，填写当前年所选月份整月日期，通过原 go 校验提交，再调用结果页“下载全部”的原 PDF 动作。调用运行中的页面逻辑可以使用其当前隐藏字段、动态参数，无需持久化凭据或硬编码静态下载链接。仅在本次导出上下文内承接预期的新窗口至同环境/同 profile 的受控 WebView，观察其下载/响应、指定桌面保存位置并确认完成；保留其他新窗口及弹窗策略。

参考微软 WebView2 NewWindowRequested/NewWindow 文档：默认新窗口未指定 NewWindow 时由 WebView2 弹出，宿主可指定同环境、同 profile、未导航的 WebView 接收：https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2newwindowrequestedeventargs.newwindow 。

直接 HTTP 接口路径尚未验证。当前采集没有 POST 请求体、函数参数和动态字段值；结果页字段超过每文档 80 项上限，部分隐藏字段未纳入，truncated=false 不代表所有字段列表完整。正式实现需进一步核对“下载全部”菜单归属和下载子窗口生命周期，不能声称一键导出已经完成。诊断开发、部署及实机分析任务已完成，本次没有自动归档，也没有修改运行程序。
