## Context

用户批准继续实现并已关闭原程序。人工采集证据见 docs/statement-export-discovery-20260930.md 和验证目录 live-evidence.json。原始银行 PDF 在默认子窗口下载，主 WebView 不收到下载事件。当前没有验证独立 HTTP 接口。

## Goals / Non-Goals

实现按钮触发、当年整月、第一账户、下载全部 PDF、桌面保存。保留现有 USB/证书/PIN/登录/弹窗逻辑。不会自行生成流水 PDF、读取或持久化 Cookie/PIN，也不做转账业务。

## Decisions

- 使用当前 WebView2 会话的 DOM 原处理器：活期入口原 taskBar.createWin 链接，jhform 的 ACC_NO 复选框及 Submit3/detailQuery，StDt/EdDt 与 Submit4/go，“下载全部”关联的 submitSelect PDF 项。不猜测函数参数、不用坐标。
- 每次点击从活期入口重新开始，避免用之前页面的账户或查询条件。每个动作前校验精确银行 origin、允许页面路径、唯一有效控件及运行代次。只选择第一条实际账户，其他复选框取消；后续验证账户在内存中匹配，不输出账号。
- 脚本分步 inspect/open-accounts/select-first/query/download；每步只有一次提交，等待阶段只是有上限的只读检查。所有页面所属 frame 从当前同源文档重新检查，最多16文档/4层。歧义不点击并报告原因。下载菜单必须能证明属于“下载全部”，不能用任意 PDF 文字猜测。
- 月份按点击时本机当前年份生成首日及月末，闰年自动处理。未来月份明确提示尚未到达；当前月份仍提交整月（不静默截断用户范围），如银行拒绝则失败提示。桌面文件名使用年月和唯一后缀，避免账号暴露与覆盖。
- 为导出操作增加独立状态，运行时禁止重复导出和环境/PIN操作，完成/失败后恢复。按钮初始化后可点击；未登录时给出明确提示而不是永久置灰。关闭程序取消并清理导出。
- 下载阶段先注册受控接收器，再触发原 PDF 项。只接管运行期间、同一银行 origin/LH 页面来源的新窗口和 PDF 下载。新 WebView 必须复用父环境与 profile，NewWindowRequested deferral 在初始化后设置 NewWindow，不手工 GET 替代原请求。接收器不影响日常弹窗处理。
- 只接受符合银行来源的 PDF（媒体类型或PDF扩展名，完成后校验 %PDF-），先下载至桌面的本次唯一临时文件，验证成功后移动为唯一 .pdf。失败清理本次文件；不得覆盖已有文件。
- 下载监听与资源在 finally 中解绑/释放。总任务限时120秒，页面阶段各30秒；下载阶段90秒，可通过取消令牌结束。诊断只记录固定阶段/错误码，不记录网页原文或敏感值。移除临时结构探针自动接入。

- 审查后的细化：导航入口在允许的活动嵌套文档中寻找，折叠菜单允许唯一精确入口；重复的上下“下载全部”菜单逐一证明归属。下载前要求结果表单或打印表单中的 ACC_NO/StDt/EdDt 与本次查询一致，并保持查询 frame 层级；无法证明时停止。旧结果页仅通过已识别的 BacktoFirst 恢复，否则提示先返回账户列表。
- PDF 只从已认领的受控子窗口接收，不接受父窗口无关联下载。取消时完成待处理 deferral、最多等待5秒排空子窗口创建，并为本次临时文件做有上限的清理重试。页面识别允许连续4次 unsupported 短暂过渡，第5次停止；歧义或明确失败立即停止，不重放提交动作。

## Risks / Trade-offs

- [菜单由插件独立挂在 BODY] → 实机后的静态插件分析确认 ccbDownload 使用 div.downloadBox，通过原按钮 mouseover 隐藏其他菜单并显示绑定菜单。复用该事件并证明隐藏到显示的转换，再校验直接标题“下载全部”和唯一原 PDF 项；预先可见的菜单通过原 mouseleave（jQuery 对应原生 mouseout）收起后再进入下一次检查。任何归属歧义不导出当前页。
- [网站响应/会话过期/无流水] → 不重放提交；限时结束并明确未完成，允许用户重新登录重试。
- [WebView2 默认子窗口下载] → 用同环境/profile的承接 WebView 保持原 opener/POST 语义；真实全流程需用户登录验收，不能把本地回归写成实测成功。

## Migration Plan

新代码和回归通过后发布至工作区外暂存，对比原发布，仅更新实际变动文件并备份系统临时目录。校验唯一入口和哈希。用户重开先安装环境刷新绑定，然后登录、选择月份、导出验收。实机未完成前保留待验收任务。
