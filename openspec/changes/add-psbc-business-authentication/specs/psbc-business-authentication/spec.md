## Purpose

为用户当前选择的邮储银行分支提供独立、可验证且默认拒绝不确定目标的企业网银认证流程，包括正确导航、当前 Key 的客户端证书选择、本地 PIN 保护、原生密码窗口续接及银行切换隔离。

## ADDED Requirements

### Requirement: 邮储业务必须打开指定企业网银入口
当用户当前选择邮储银行并明确点击“启动业务”时，系统 SHALL 启动邮储独立业务会话并导航到 `https://corpebank.psbc.com/#/login`。在用户点击“启动业务”之前，系统 MUST NOT 因邮储 Key 已插入而自动导航或读取 PIN。

#### Scenario: Key 已插入后启动邮储业务
- **WHEN** 用户选择邮储银行、邮储 Key 已就绪并点击“启动业务”
- **THEN** 系统启动邮储业务会话并打开 `https://corpebank.psbc.com/#/login`

#### Scenario: 启动业务后再插入 Key
- **WHEN** 用户选择邮储银行并点击“启动业务”，随后插入受支持的邮储 Key
- **THEN** 系统在同一邮储业务会话中继续检测、证书选择和认证流程

#### Scenario: 尚未明确启动业务
- **WHEN** 用户选择邮储银行但尚未点击“启动业务”
- **THEN** 系统不导航邮储网站、不读取邮储 PIN，也不发起客户端证书认证

### Requirement: 客户端证书必须与当前邮储 Key 唯一对应
系统 MUST 只处理来自明确授权的邮储 HTTPS 主机和端口的客户端证书请求，并 MUST 根据当前检测到的邮储 Key 厂商、Token 身份以及证书私钥提供程序的只读证据筛选证书。只有恰好一个候选证书与当前 Key 和授权端点匹配时，系统才 SHALL 自动选择该证书；系统 MUST NOT 把截图中的单个主题、序列号或指纹作为所有邮储 Key 的通用规则。

#### Scenario: 当前 Key 恰好匹配一个证书
- **WHEN** `corpebank.psbc.com:443` 请求客户端证书，并且候选集合中恰好一个证书的私钥提供程序证据与当前邮储 Key 对应
- **THEN** 系统自动选择该证书并继续当前认证尝试

#### Scenario: 没有证书匹配当前 Key
- **WHEN** 授权端点请求客户端证书，但候选集合中没有证书与当前邮储 Key 对应
- **THEN** 系统不选择其他证书、不读取或提交 PIN，并以可诊断错误终止当前认证尝试

#### Scenario: 多个证书匹配当前 Key
- **WHEN** 授权端点请求客户端证书，但有多个候选证书满足当前邮储 Key 的匹配条件
- **THEN** 系统不按枚举顺序猜测证书、不提交 PIN，并报告证书匹配冲突

#### Scenario: 非授权端点请求证书
- **WHEN** 除明确配置的邮储 HTTPS 主机和端口之外的页面或重定向请求客户端证书
- **THEN** 系统拒绝自动选择证书，并且不读取或提交邮储 PIN

### Requirement: 邮储 PIN 必须独立并保存在本机受保护凭据中
系统 MUST 为邮储银行使用独立于建设银行的凭据目标，并 MUST 只把邮储 PIN 保存到当前 Windows 用户的 Windows Credential Manager。邮储 PIN MUST NOT 写入源代码、JSON、普通文件、环境变量、命令行、剪贴板、网页内容、页面脚本、日志、诊断输出或 OpenSpec 文件。

#### Scenario: 用户设置邮储 PIN
- **WHEN** 用户在当前银行为邮储时通过本机密码输入控件设置或更换 PIN
- **THEN** 系统只更新邮储凭据目标，清除短生命周期缓冲区，并且不修改建设银行凭据

#### Scenario: 用户删除邮储 PIN
- **WHEN** 用户请求删除当前邮储 PIN
- **THEN** 系统删除邮储凭据及其非秘密验证状态，并且不删除或改变建设银行凭据

#### Scenario: 当前选择建设银行
- **WHEN** 用户当前选择建设银行并启动业务
- **THEN** 系统不读取邮储凭据，也不把邮储 PIN 用于任何建设银行窗口或证书请求

### Requirement: 邮储原生密码窗口续接必须严格授权
系统 MUST 只在当前邮储业务会话、当前 Key、授权客户端证书请求和单次认证尝试均有效时，向通过邮储独立策略完整匹配的唯一“校验UK密码”原生窗口提交一次 PIN。匹配 MUST 覆盖进程身份、可执行文件路径或受信关系、签名或哈希、Windows 会话、完整性级别、窗口类和标题、owner 或父子关系、唯一密码输入控件及唯一确认按钮。

#### Scenario: 唯一邮储密码窗口完整匹配
- **WHEN** 唯一候选窗口满足邮储策略的全部身份条件，并且当前授权证书认证正在等待私钥操作
- **THEN** 系统聚焦唯一密码输入控件、重新复核窗口身份、输入一次已保存 PIN、确认输入已完整处理，并激活唯一确认按钮一次

#### Scenario: 窗口身份不完整或发生变化
- **WHEN** 候选窗口的任一进程、签名、会话、完整性、标题、窗口类、owner、控件或焦点条件不匹配，或者在输入前发生变化
- **THEN** 系统不输入任何 PIN 字符、不点击确认，并以失败关闭结束当前认证尝试

#### Scenario: 出现多个相似窗口
- **WHEN** 同时存在多个满足部分或全部邮储窗口条件的候选窗口
- **THEN** 系统不选择任一窗口、不提交 PIN，并报告窗口匹配冲突

#### Scenario: PIN 输入未被完整处理
- **WHEN** 目标输入控件未在限定时间内处理完整的 PIN 字符数，或者确认按钮不可用
- **THEN** 系统不点击确认、不在同一认证周期重试，并且不读取或记录输入框文本及字符数

### Requirement: 每个邮储认证周期最多自动提交一次 PIN
系统 MUST 为每次明确启动或有效重新插入产生的邮储认证周期维护单次尝试状态。页面刷新、重复证书请求、重复设备通知和重复点击“启动业务” MUST NOT 在同一周期触发第二次 PIN 自动提交。

#### Scenario: 同一周期出现重复证书请求
- **WHEN** 当前邮储认证周期已经向授权窗口提交过一次 PIN，随后页面刷新或再次请求客户端证书
- **THEN** 系统不再次自动提交 PIN

#### Scenario: Key 拔出后重新插入
- **WHEN** 当前邮储 Key 被真实拔出，旧会话完成撤销和清理后重新插入
- **THEN** 系统创建新的邮储认证周期，并允许该新周期执行一次受约束的认证尝试

#### Scenario: 认证超时或被取消
- **WHEN** 证书请求、窗口等待或 TLS 认证超时，或者当前会话被取消
- **THEN** 系统清除短生命周期 PIN 缓冲区、撤销窗口续接授权，并且不在原周期自动重试

### Requirement: 邮储和建设银行运行时必须完全隔离
系统 SHALL 只构造和运行用户当前选择银行的认证分支。邮储分支 MUST 使用独立的认证 ID、凭据目标、窗口策略和 WebView2 用户数据目录，MUST NOT 加载建设银行 UKey 扩展，也 MUST NOT 执行建设银行证书登录页面脚本或协调器。

#### Scenario: 选择邮储银行启动业务
- **WHEN** 用户选择邮储银行并启动业务
- **THEN** 只有邮储检测、邮储认证和邮储浏览器会话运行，建设银行扩展、脚本和认证策略均不运行

#### Scenario: 从邮储切换到建设银行
- **WHEN** 邮储业务会话存在时用户切换到建设银行
- **THEN** 系统先撤销邮储证书请求和窗口续接授权、清除邮储短生命周期秘密并释放邮储浏览器会话，再创建建设银行运行时

#### Scenario: 旧邮储会话产生延迟回调
- **WHEN** 银行切换完成后，旧邮储设备、证书、窗口或导航处理产生延迟回调
- **THEN** 系统忽略该回调，并且不改变当前建设银行状态或提交任何 PIN

### Requirement: 邮储认证诊断不得泄露秘密
系统 SHALL 提供显式启用的无秘密诊断，用于观察客户端证书候选的公开身份和私钥提供程序元数据，以及邮储原生密码窗口的公开进程和控件结构。普通运行日志 MUST NOT 记录证书持有人敏感值、Token 身份、PIN、输入框内容或可还原 PIN 的数据；诊断模式也 MUST NOT 读取密码输入框内容。

#### Scenario: 采集证书匹配证据
- **WHEN** 操作者显式启用邮储证书诊断并触发授权端点的证书请求
- **THEN** 系统输出建立匹配规则所需的非秘密候选元数据和分类结果，但不读取 PIN 或执行私钥签名

#### Scenario: 采集窗口匹配证据
- **WHEN** 操作者显式启用邮储窗口诊断并触发“校验UK密码”窗口
- **THEN** 系统输出进程、签名、窗口及控件身份结构，但不读取输入框文本、不记录 PIN，也不自动提交

### Requirement: 只有完整邮储 TLS 认证成功才可标记验证完成
系统 MUST 区分“邮储 PIN 已保存”和“当前邮储 Key、证书、窗口续接及目标 TLS 已验证”。只有授权目标的客户端证书 TLS 认证成功后，系统才 SHALL 写入与邮储认证配置绑定的非秘密验证标记。

#### Scenario: 邮储认证完整成功
- **WHEN** 当前 Key 的唯一证书被选中、授权窗口续接成功且目标 TLS 客户端证书认证完成
- **THEN** 系统将当前邮储认证配置标记为已验证，并继续展示邮储登录页面

#### Scenario: 证书、窗口或 TLS 任一阶段失败
- **WHEN** 当前认证尝试在证书匹配、窗口续接、PIN 确认或目标 TLS 任一阶段失败
- **THEN** 系统不写入成功验证标记，并保留不包含 PIN 的可诊断失败状态
